> **읽기 전 참고** — Windows 11에서 발생하는 와이파이 연결 문제를 해결하기 위한 한국어 원고입니다. 실제 기기에서 모든 단계를 시험했다는 의미는 아닙니다. 제조사·Windows 버전별 차이를 최종 검수한 뒤 게시해야 합니다.

## 먼저 확인할 핵심 3가지

Windows 11에서 **와이파이 연결됨**이라고 표시되지만 웹사이트가 열리지 않는다면, PC와 공유기 사이의 연결과 공유기에서 인터넷으로 나가는 연결을 구분해야 합니다. 와이파이에 연결됐다고 해서 인터넷까지 정상인 것은 아닙니다.

1. 휴대전화의 **모바일 데이터를 끄고** PC와 같은 와이파이에 연결한 후 서로 다른 웹사이트 두 곳을 열어보세요.
2. 휴대전화도 인터넷이 안 되면 공유기·모뎀·통신사 회선을 먼저 확인하고, 휴대전화는 되는데 PC만 안 되면 Windows 설정을 점검하세요.
3. **Windows 11 도움말 보기(Get Help)**의 네트워크 및 인터넷 문제 해결사를 실행하세요. 문제가 해결됐다면 추가 조작을 멈추세요.

**네트워크 초기화는 처음부터 실행하지 마세요.** VPN, 가상 네트워크 어댑터 및 기존 설정이 영향을 받을 수 있습니다.

## 증상에 따른 점검 순서

| 증상 | 먼저 확인할 곳 | 권장하는 첫 조치 |
| --- | --- | --- |
| 같은 공유기의 모든 기기가 접속 불가 | 통신사·공유기·모뎀 | 장애 공지 확인 및 장비 전원 재시작 |
| 휴대전화는 정상인데 PC만 실패 | Windows PC | 문제 해결사 및 Wi-Fi 재연결 |
| VPN 사용 시에만 실패 | VPN·보안 정책 | 개인 PC는 VPN 상태 점검, 회사 PC는 IT 문의 |
| 특정 웹사이트만 열리지 않음 | 해당 사이트·앱·브라우저 | 다른 사이트·브라우저로 비교 |
| 유선 인터넷은 정상, 와이파이만 실패 | 무선 어댑터·무선 설정 | Wi-Fi와 드라이버 점검 |
| 절전 모드 복귀 후 끊김 | 드라이버·전원 관리 | 장애 시점 기록 및 업데이트 확인 |
| 인터넷은 되지만 연결 상태에 경고 표시 | Windows의 연결 감지 | 실제 웹·앱 동작부터 확인 |

증상만으로 원인을 확정할 수는 없습니다. 아래 순서로 비교하며 문제가 해결되는 단계에서 멈추면 됩니다.

## 1. 다른 기기에서 같은 와이파이 사용하기

가장 먼저 해야 할 일은 **동일한 무선 네트워크를 이용하는 다른 기기와 비교**하는 것입니다. 휴대전화가 자동으로 모바일 데이터를 사용한다면 공유기가 고장 났어도 인터넷에 연결된 것처럼 보일 수 있습니다.

- 휴대전화의 모바일 데이터를 끄고 집 와이파이에 접속합니다.
- 서로 관련 없는 웹사이트 두 곳을 열어봅니다.
- 휴대전화와 PC 모두 실패하면 통신사 장애 여부와 공유기 상태를 확인합니다.
- 휴대전화는 정상이라면 PC 설정과 무선 어댑터로 범위를 좁힙니다.

모뎀과 공유기가 따로 있다면 전원을 끄고 약 30초 기다린 뒤 **모뎀을 먼저 켜고**, 모뎀 연결이 안정되면 공유기를 다시 켭니다. 가족이 사용하는 인터넷도 일시적으로 끊기므로 사용 중인 사람이 없는지 확인하세요.

**공장 초기화 버튼은 누르지 마세요.** 단순 전원 재시작과 달리 공유기 관리자 암호, Wi-Fi 이름과 기타 설정이 삭제될 수 있습니다.

## 2. Windows 11 네트워크 문제 해결사 실행

Microsoft는 Windows 11 사용자가 도움말 보기(Get Help) 앱의 **네트워크 및 인터넷 문제 해결사**를 먼저 실행하도록 안내합니다.

1. 시작 메뉴에서 **도움말 보기**를 검색하고 실행합니다.
2. 네트워크 또는 인터넷 연결 문제 해결 안내를 선택합니다.
3. 화면 지시에 따라 진단을 실행하고, 제시되는 설정 변경의 내용을 확인합니다.
4. 진단이 끝나면 서로 다른 웹사이트 두 곳을 열어 정상 연결됐는지 점검합니다.

메뉴 이름이나 진입 경로는 Windows 버전에 따라 다를 수 있습니다. 문제 해결사가 원인을 찾지 못했다고 해서 바로 전체 네트워크 초기화를 해야 한다는 의미는 아닙니다.

## 3. Wi-Fi 설정과 저장된 네트워크 확인

**설정 → 네트워크 및 인터넷 → Wi-Fi**로 이동해 Wi-Fi를 껐다가 켜고 연결을 다시 시도합니다. 비행기 모드가 꺼져 있는지도 확인하세요.

다시 연결해도 문제가 같다면 **알려진 네트워크 관리**에서 해당 네트워크를 선택하고 **삭제(잊어버리기)** 한 후 다시 연결할 수 있습니다. 이때 Wi-Fi 암호를 다시 입력해야 하므로 먼저 암호를 확인하세요.

공유기에서 2.4GHz와 5GHz를 별도 이름으로 제공한다면 다른 주파수 대역에서도 같은 문제가 발생하는지 확인합니다. 다른 대역에서 접속되는지만 비교하고 어느 주파수 대역이 항상 더 우수하다고 단정하지 않습니다.

회사·학교에서 관리하는 네트워크는 인증서나 추가 인증이 필요할 수 있습니다. 관리자가 배포한 프로필을 삭제하기 전에 담당자에게 문의하세요.

## 4. VPN, 프록시, 공용 와이파이 로그인 점검

VPN을 켰을 때만 인터넷이 끊긴다면 무선 연결 문제가 아니라 VPN이나 네트워크 정책 문제일 수 있습니다.

- 개인 PC에서는 VPN 연결을 잠시 끊고 다른 웹사이트를 열어 비교할 수 있습니다. 테스트 후 필요한 VPN을 다시 켭니다.
- 회사·학교 PC에서는 정책상 VPN·프록시 설정이 필수일 수 있습니다. 임의로 변경하거나 우회하지 말고 IT 담당자에게 문의하세요.
- 카페·호텔 와이파이는 접속 후 별도의 로그인 화면이나 이용 약관 확인이 필요할 수 있습니다. 해당 장소의 공식 안내에 따르세요.
- **설정 → 네트워크 및 인터넷 → 프록시**에서 예상하지 못한 수동 프록시가 있는지 확인합니다. 용도를 모르면 무작정 삭제하지 마세요.

특정 앱 하나만 실패한다면 Windows 전체가 아니라 해당 앱, 방화벽 규칙 또는 서비스 자체에 문제가 있을 수 있습니다.

## 5. IP 주소, 기본 게이트웨이와 DNS 살펴보기

시작 메뉴에서 **명령 프롬프트**를 열고 다음을 실행합니다.

```txt
ipconfig /all
```

결과에서 무선 LAN 어댑터의 **IPv4 주소**, **기본 게이트웨이**, **DNS 서버** 항목을 확인하세요.

| 확인 내용 | 해석 | 주의 |
| --- | --- | --- |
| IPv4가 169.254로 시작 | DHCP로 정상 주소를 받지 못했을 가능성 | 공유기 DHCP·연결 상태부터 점검 |
| 192.168 또는 10으로 시작하는 사설 주소 | 로컬 네트워크 주소가 할당됨 | 인터넷 접속 성공을 보증하지 않음 |
| 기본 게이트웨이가 없음 | 네트워크 구성 문제 가능성 | 특별한 네트워크 구성에서는 예외 존재 |
| DNS 서버가 비어 있거나 예상과 다름 | 이름 확인 설정 점검 필요 | 회사 지정 DNS라면 임의 변경 금지 |

공유기와 통신하는지 확인하려면 실제 기본 게이트웨이 주소로 핑 테스트를 실행할 수 있습니다.

```txt
ping 192.168.1.1
```

위 숫자는 **예시 주소**입니다. 반드시 실제 기본 게이트웨이 주소로 바꾸세요. 응답이 없더라도 공유기가 핑을 차단하는 경우가 있으므로 고장이라고 확정할 수 없습니다. 응답이 있어도 외부 인터넷 연결이 정상이라는 뜻은 아닙니다.

**보안 주의:** 명령 출력에는 내부 주소와 장치 관련 정보가 담길 수 있습니다. 전체 결과를 공개 게시판에 그대로 올리지 마세요.

## 6. IP 주소 갱신 및 DNS 캐시 정리

앞의 간단한 방법이 효과가 없고, 본인이 관리하는 PC라면 IP 갱신과 DNS 캐시 비우기를 시도할 수 있습니다.

먼저 작업을 저장합니다. **원격 데스크톱으로 접속 중인 PC라면 실행하지 않는 편이 안전합니다.** IP 주소를 해제하면 원격 연결이 바로 끊길 수 있기 때문입니다.

관리자 권한으로 명령 프롬프트를 열어 아래 명령을 한 줄씩 실행합니다.

```txt
ipconfig /release
ipconfig /renew
ipconfig /flushdns
```

각 명령의 의미는 다음과 같습니다.

- **/release:** DHCP로 할당된 IP 주소를 해제합니다. 현재 연결이 일시적으로 끊어질 수 있습니다.
- **/renew:** DHCP 서버에 새 주소를 요청합니다.
- **/flushdns:** Windows DNS 확인자 캐시를 지웁니다. 개인 문서나 사진은 삭제하지 않습니다.

오류 메시지가 나오면 기록하고, 각 단계 이후 연결 상태를 확인합니다. 문제가 해결됐다면 추가 명령을 실행하지 마세요.

Microsoft는 더 넓은 범위의 네트워크 재설정 명령도 안내하지만, 회사 PC나 특수 네트워크 구성에서는 영향을 평가한 뒤 실행해야 합니다. 모든 명령을 이유 없이 한꺼번에 입력하는 방법은 권장하지 않습니다.

## 7. 무선 네트워크 어댑터 드라이버 점검

문제가 Windows 업데이트 후 시작됐거나 절전 상태에서 복귀할 때만 반복된다면 드라이버를 점검합니다.

1. **설정 → Windows 업데이트**에서 최근 업데이트 내역과 대기 중인 업데이트를 확인합니다.
2. PC 제조사 공식 지원 페이지에서 정확한 모델에 맞는 무선 네트워크 드라이버를 확인합니다.
3. 인터넷이 되지 않는 경우 다른 PC에서 제조사가 제공하는 드라이버를 다운로드해 USB로 가져올 수 있습니다.
4. 드라이버 제거·재설치는 올바른 설치 파일과 복구 방법을 준비한 뒤 진행합니다.

Windows가 재시작 후 드라이버를 자동 설치할 수 있지만 반드시 성공하는 것은 아닙니다. 다른 연결 수단이 없고 백업 드라이버도 없다면 무작정 제거하지 마세요.

## 8. 네트워크 초기화는 마지막 수단

공유기 장애, Windows 문제 해결사, 저장된 와이파이, IP·DNS, 드라이버를 확인한 뒤에도 해결되지 않을 때만 전체 초기화를 고려하세요.

Windows 11 일반적인 경로는 다음과 같습니다.

**설정 → 네트워크 및 인터넷 → 고급 네트워크 설정 → 네트워크 초기화**

이 작업은 네트워크 어댑터와 관련 설정을 제거·재설정하며 다시 시작한 후 재구성합니다. VPN 클라이언트나 Hyper-V 가상 스위치 등을 다시 설정해야 할 수 있고, 네트워크 프로필이 공용으로 바뀔 수도 있습니다.

실행 전 체크할 사항입니다.

- 현재 Wi-Fi 암호를 알고 있는가?
- 고정 IP, 회사 VPN, 프록시, 가상 머신을 사용하는가?
- 기존 설정을 기록해 두었는가?
- 관리자 승인과 복구 방법을 확보했는가?

업무용 PC에서는 IT 담당자와 먼저 상의하세요.

## 인터넷은 되는데 '인터넷 없음' 표시가 나오는 이유

Windows는 인터넷 접근 여부를 판별하기 위해 자체적인 연결 확인 요청을 사용합니다. 프록시, 방화벽 또는 관리되는 네트워크 정책이 해당 요청에 영향을 주면 웹사이트는 열리는데 Windows 상태 아이콘만 경고를 표시할 수 있습니다.

서로 다른 웹사이트와 필요한 앱들이 정상 작동한다면 **아이콘 하나를 고치기 위해 네트워크를 초기화하지 마세요.** 학교나 회사 네트워크라면 담당자가 연결 감지 방식을 제한했는지 확인하는 편이 낫습니다.

## 반복해서 끊기는 경우 기록할 정보

연결이 자주 끊긴다면 시간과 조건을 기록합니다. 예를 들어 잠자기 모드 복귀 직후인지, VPN 실행 직후인지, 특정 공유기에서만 발생하는지, Windows 업데이트 후부터 시작됐는지 확인합니다.

같은 시각에 휴대전화도 끊기는지 함께 기록하면 제조사·통신사·IT 담당자가 원인을 좁히는 데 도움이 됩니다. 와이파이 암호, 기기 내부 정보 등을 불필요하게 공유하지 마세요.

## 해결 여부 확인 체크리스트

- [ ] 다른 기기를 같은 와이파이에 연결해 PC만의 문제인지 확인했다.
- [ ] 서로 다른 웹사이트 두 곳이 정상적으로 열린다.
- [ ] 웹브라우저 외의 인터넷 사용 앱도 정상 작동한다.
- [ ] 와이파이를 끊었다 다시 연결해도 접속이 유지된다.
- [ ] VPN이 필요한 경우 다시 연결해 업무용 서비스에 접속할 수 있다.
- [ ] 불필요한 네트워크 초기화를 하지 않았다.

## 자주 묻는 질문

### Q. 와이파이는 연결됐는데 왜 인터넷이 안 되나요?

PC가 공유기와 연결돼도 통신사 회선, IP 주소 할당, DNS 같은 다른 구성 요소에서 문제가 발생할 수 있습니다. 다른 기기를 같은 와이파이에 연결해 비교하는 것이 가장 먼저 할 점검입니다.

### Q. DNS 캐시를 지우면 사진이나 파일도 없어지나요?

아닙니다. Windows의 DNS 확인자 캐시를 지우는 작업이며 사진·문서를 삭제하지 않습니다.

### Q. 공유기를 재시작해도 안 되면 공장 초기화를 해야 하나요?

바로 초기화하지 마세요. 공유기 초기화로 기존 연결 정보가 삭제될 수 있습니다. 다른 기기도 접속하지 못하는지 확인하고 통신사 또는 공유기 제조사 지원을 받으세요.

### Q. 회사 노트북의 VPN과 프록시를 끄면 되나요?

회사 정책을 따르세요. 관리자가 지정한 설정은 임의로 변경하지 않는 것이 안전합니다.

### Q. 인터넷은 되는데 연결 아이콘에만 경고가 표시됩니다.

Windows의 연결 확인 요청이 제한돼 있을 수 있습니다. 실제 웹과 앱 이용이 정상인지 먼저 확인하고 조직의 관리 정책을 점검하세요.
